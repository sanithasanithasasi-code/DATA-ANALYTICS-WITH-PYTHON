# Online Education Data Analysis Using Python

## 📌 Project Overview

This project focuses on analysing students' online education experiences using Python and Data Analytics.

The main purpose of this project is to understand the factors that influence students' online learning experiences, academic performance, and satisfaction levels.

The analysis covers internet facilities, device usage, study habits, social media usage, online interaction, doubt clearing, and student satisfaction.

## 🎯 Project Objectives

- Analyse students' online education experiences.
- Understand the factors affecting student satisfaction.
- Analyse internet facilities and devices used for online learning.
- Study students' social media usage and gaming habits.
- Examine the relationship between online interaction and student satisfaction.
- Identify important patterns and trends in the dataset.
- Generate meaningful insights to improve online education.

## 💡 Key Findings

- The dataset contains 1,033 students.
- Laptops are the most commonly used devices for online classes.
- Most students belong to the middle-class economic group.
- Average satisfaction is the most common satisfaction level.
- Higher online interaction is generally associated with better satisfaction.
- Better doubt clearing with faculties is associated with higher satisfaction.
- Online interaction and doubt clearing have a strong positive correlation of 0.72.
- Students spend an average of 2.64 hours on social media daily.
